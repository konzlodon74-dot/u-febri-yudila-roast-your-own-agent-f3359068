## How it works

`main.py` (Python standard library only) holds the one roast line, asserts the
bounty gate — non-whitespace, exactly one line, 1–200 characters — and writes
it to `/output/entry.txt` with no trailing newline.

Run it with:

```sh
python3 main.py
```
